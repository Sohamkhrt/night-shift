Here's what was changed and why for each bug:

**Bug 1 — circular import** (`runner.py` ↔ `diary.py`)

- `runner.py`: removed the top-level `from nightshift import diary as diary_module`. Added `diary_module = None` at module level as a sentinel. Inside `run_all()`, added a lazy import that sets the global on first call.
- `diary.py`: replaced the top-level `from nightshift.runner import DiffStats, RunEvent, RunLog` with:
  - `from nightshift.safety import DiffStats` — `DiffStats` was always defined in `safety.py`, this was the wrong source.
  - `if TYPE_CHECKING: from nightshift.runner import RunEvent, RunLog` — satisfies type checkers without executing at import time.
  - Deferred `from nightshift.runner import RunEvent` / `RunLog` inside `_event_from_dict` and `_run_log_from_dict` — the only places that construct these objects at runtime.

This breaks the cycle so `import nightshift.runner`, `import nightshift.diary`, and `import nightshift.cli` all work in any order.

---

**Bug 2 — `UnicodeEncodeError` on Windows** (`cli.py`)

Removed the `👻` from the Typer app `help=` string. The rest of the help text is ASCII-safe.

---

**Bug 3 — `test_no_labels_shows_none`** (`tests/test_agent.py`)

Changed `labels or ["night-shift"]` to `["night-shift"] if labels is None else labels`. The old expression replaced an empty list (falsy) with the default; the new one only substitutes when the caller passed nothing at all, so `make_issue(labels=[])` now correctly produces an `Issue` with an empty labels list, and `build_prompt` returns `"(none)"` as expected.

---

**Bug 4 — `DeadlineExceeded` in `test_round_trip`** (`tests/test_config.py`)

Added `deadline=None` to `@settings(max_examples=50, ...)`. The test writes temp files on each example; the default 200ms Hypothesis deadline is too tight for that I/O.
